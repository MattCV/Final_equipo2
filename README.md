# Dataset

<https://www.kaggle.com/datasets/mirichoi0218/insurance>

**Idea del problema:** Costo del seguro médico según edad, IMC y hábito de fumar.

## Librerías

- pandas
- numpy
- matplotlib
- seaborn
- scipy
- statsmodels

## Cómo ejecutar

1. Crear/activar el entorno virtual e instalar las librerías anteriores.
2. Abrir `analisis.ipynb` y ejecutar todas las celdas de principio a fin (`Run All`).
3. Los datos se leen desde `./datos/insurance.csv`.
